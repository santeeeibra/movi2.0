# Improve UI Skill
Audita y mejora la interfaz de usuario de componentes construidos enfocándote en:
- Consistencia de espaciados y rejillas (8-point grid).
- Jerarquía visual clara y contraste de colores (ej. regla 60/30/10).
- Alineación precisa y estados interactivos (hover, active, focus).
- Estética moderna y limpia orientada a aplicaciones móviles nativas.
